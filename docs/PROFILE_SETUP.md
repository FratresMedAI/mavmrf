# Fratres-X-AI GitHub org checklist (manual)

MAVMRF lives at https://github.com/Fratres-X-AI/mavmrf.

1. Open https://github.com/Fratres-X-AI
2. Pin **mavmrf** on the org profile (or a personal profile that links the org) if you want it featured
3. Confirm the repo homepage is `https://fratres-x.com`
4. After transfer, re-enable Zenodo under the **Fratres-X-AI** GitHub connection (see [ZENODO_SETUP.md](ZENODO_SETUP.md))

## Done when

- Repo URL is `Fratres-X-AI/mavmrf`
- Org or personal pin shows mavmrf (optional)
- Repo homepage shows fratres-x.com
