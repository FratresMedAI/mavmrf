# SOLUTION BRIEF

## Project
Maritime Autonomous Vehicle Monitoring and Response Framework (MAVMRF)

## Solicitation Alignment
DIU Robotic Exclusion & Engagement Framework (REEF)  
Solution Component 1: Detect, Track, and Classify Capabilities

## Solution Overview
MAVMRF is a modular, simulation-first Python framework for maritime monitoring and operator decision support. It provides an end-to-end pipeline that ingests multi-sensor inputs, performs AI-assisted object detection and classification, fuses observations, maintains track continuity, and publishes operator-facing reports and visualizations.

Core pipeline:
- Multi-sensor input (sonar, acoustic, optical, magnetic)
- Preprocessing and configurable clutter filtering
- Detection/classification (YOLOv8 wrapper, marine classes)
- Weighted multi-sensor fusion
- SORT-style multi-object tracking
- Rule-based advisory/report generation

## Component 1 Capabilities
- **Detect:** Produces per-contact detection outputs from multi-sensor streams with frame-by-frame reporting.
- **Track:** Maintains persistent track IDs and trajectory history through time.
- **Classify:** Supports 8 marine classes and report-level contact type differentiation (`biological_like`, `non_biological_like`, `unknown`).

Operator-facing report fields include:
- `bearing`
- `estimated_range`
- `bearing_rate`
- class label and confidence
- track identity/history

## Technical Differentiators
- Multi-sensor fusion for more stable state estimates.
- Tunable clutter/false-alarm sensitivity via CLI (`--filter-sensitivity low|medium|high`).
- Open architecture adapter contract for fixed/mobile sensor feed integration (`interfaces/sensor_adapter.py`).
- Structured JSON outputs plus visual track artifacts for rapid operator interpretation.
