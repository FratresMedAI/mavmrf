# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.2.x   | Yes       |
| < 0.2   | No        |

## Reporting a vulnerability

MAVMRF is a portfolio / research prototype that uses **simulated sensor data**. Even so, please report security issues privately.

**Do not open a public GitHub issue for security reports.**

Prefer one of:

1. [GitHub Security Advisories](https://github.com/Fratres-X-AI/mavmrf/security/advisories/new) for this repository
2. Contact the maintainer via the GitHub profile [@FratresMedAI](https://github.com/FratresMedAI) (org admin for [Fratres-X-AI](https://github.com/Fratres-X-AI))

Please include:

- Description of the issue
- Steps to reproduce
- Impact assessment (if known)
- Suggested fix (optional)

You can expect an acknowledgment within a few days when possible. There is no formal SLA for this project.
